## Task 2: Executing System Information Commands
This task focuses on identifying the user, host, and general system status.

**System Discovery Commands:**
| Command | Description |
| :--- | :--- |
| `whoami` | Displays the current logged-in username. |
| `hostname -s` | Shows the short name of the host/machine. |
| `uptime -p` | Shows how long the system has been running in a "pretty" format. |
| `who -H -a` | Provides a detailed list of logged-in users, including process IDs (PID). |
| `id [user]` | Displays the UID (User ID) and GID (Group ID) for a specific user. |

### Working with Dates and Calendars
Linux allows for flexible time and date manipulation via the `date` and `cal` commands.

* **Time Zone Overrides:** You can check the time in different regions without changing system settings:
  - New York: `TZ=America/New_York date`
  - Los Angeles: `TZ=America/Los_Angeles date`
* **Calendars:**
  - `cal -j`: Displays the **Julian date** (days numbered consecutively from 1 to 365).
  - `cal -s`: Standard view (Sunday as the first day).
  - `cal -m`: European view (Monday as the first day).

### Identifying User and Group IDs
To manage permissions effectively, you need to know the unique identifiers assigned to a user.

* **Command:** `id ec2-user`
* **Purpose:** Displays the UID (User ID), GID (Group ID), and the specific groups the user belongs to.

**Example Output Breakdown:**
- **uid=1000(ec2-user):** The unique numerical ID for the user.
- **gid=1000(ec2-user):** The primary group ID.
- **groups=1000(ec2-user), 4(adm), 10(wheel):** Other groups the user is a member of. 

> **📝 Technical Note:** Being part of the `wheel` group is what typically allows `ec2-user` to use the `sudo` command to perform administrative tasks.

## Task 3: Workflow Optimization (History & Search)
Efficiency in Linux comes from not typing the same command twice.

### 1. Command History
Run `history` to view the list of all commands executed in the current session. Each command is assigned a number for easy reference.

### 2. Reverse Search (`CTRL + R`)
Instead of scrolling through hundreds of lines, use **Reverse-i-search**:
1. Press `CTRL + R`.
2. Type a fragment of the command (e.g., `TZ`).
3. Press `Tab` to bring the command to the prompt for editing.

### 3. The "Bang-Bang" Shortcut (`!!`)
Typing `!!` executes the very last command again. 
* *Common Use Case:* If you forget `sudo`, you can type `sudo !!` to run the previous command with elevated privileges.

## 💡 Pro-Tips for Workflow Efficiency

1. **The Power of Tab:** Always use the `Tab` key. If it doesn't autocomplete, press it twice to see all available possibilities. It prevents typos.
2. **Clearing the Screen:** Use `CTRL + L` or type `clear` to clean up your terminal view without losing your history.
3. **History Shortcuts:** - `!n`: Re-runs command number `n` from your history.
   - `!string`: Re-runs the most recent command starting with "string".
