# Lab 243: Linux Software Administration and AWS CLI Configuration

## Objective
Master software management using the `yum` package manager and establish programmatic connectivity to AWS. This lab covers system updates, package rollbacks, and the installation/configuration of the AWS Command Line Interface (CLI).

## Key Concepts
* **Package Manager (`yum`):** The standard utility for RPM-based systems (like Amazon Linux/Red Hat) to install, update, and remove software.
* **Idempotency:** The ability to run an update command multiple times without changing the system if it is already up to date.
* **AWS CLI:** A unified tool to manage your AWS services from the terminal.
* **Access Keys:** Credentials (Access Key ID and Secret Access Key) used to authenticate the CLI with your AWS account.

## Task 2: System Updates and Upgrades
Maintaining security and stability through regular updates.

**Workflow:**
1. **Check for Updates:** `sudo yum -y check-update`
2. **Security Only:** `sudo yum update --security` (Focuses on patches that fix vulnerabilities).
3. **Full Upgrade:** `sudo yum -y upgrade` (Updates all packages to the latest versions).
4. **Install Service:** `sudo yum install httpd -y`

---

## Task 3: Rolling Back with Yum History
One of the most powerful features of `yum` is the ability to undo transactions if an installation causes issues.

**Commands:**
* **List Transactions:** `sudo yum history list` (Note the ID of the transaction you want to revert).
* **View Details:** `sudo yum history info <ID>` (Shows exactly what happened during that transaction).
* **Undo Changes:** `sudo yum -y history undo <ID>`
  * *Example:* If ID 2 was the installation of `httpd`, running `undo 2` will uninstall it and its dependencies.

## Task 4: Installing the AWS CLI
Since the AWS CLI v2 is not always in default repositories, we perform a manual installation.

**Installation Steps:**
1. **Download:** `curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"`
2. **Unzip:** `unzip awscliv2.zip`
3. **Install:** `sudo ./aws/install`
4. **Verify:** `aws --version`

## Task 5: Configuring AWS CLI Connectivity
To interact with AWS resources, the CLI needs your credentials and preferred region.

**Configuration Process:**
1. **Init:** Run `aws configure`.
2. **Credentials:** Although prompted, the best practice in this lab is to manually edit the credentials file:
   ```bash
   sudo nano ~/.aws/credentials
   ```
3. **Template:**
    ```bash
    [default]
    aws_access_key_id=YOUR_ACCESS_KEY
    aws_secret_access_key=YOUR_SECRET_KEY
    aws_session_token=YOUR_SESSION_TOKEN
    ```
4. **Testing:** Run a describe command to verify connectivity:
    ```bash
    aws ec2 describe-instance-attribute --instance-id [YOUR_ID] --attribute instanceType
    ```


## 💡 Pro-Tips for Software Administration

1. **Yum vs. DNF:** In the latest Linux distributions (like Amazon Linux 2023), `dnf` has replaced `yum`. The syntax is nearly identical, but `dnf` offers better performance and dependency management.
2. **Security Patches First:** In a production environment, it is best practice to run `yum update --security` regularly. This patches vulnerabilities without the risk of breaking your applications with major version upgrades.
3. **Session Tokens:** When using temporary credentials (common in AWS Labs), you **must** include the `aws_session_token` in your configuration. Without it, your access will be denied even if your keys are correct.
4. **AWS CLI Output:** While this lab uses `json`, you can also use `--output table` or `--output text` in your commands to make the data easier to read depending on your needs.
5. **Undo with Caution:** `yum history undo` is powerful, but remember it will also remove any dependencies that were installed with that package, which might affect other software.

## Command Reference Summary

| Command | Action |
| :--- | :--- |
| `yum check-update` | Queries repositories to see what software has newer versions. |
| `yum update --security` | Installs only the patches categorized as security fixes. |
| `yum history list` | Displays a numbered log of all past package transactions. |
| `yum history undo [ID]` | Reverts the changes made by a specific transaction ID. |
| `curl -o [filename]` | Downloads a file from a URL and saves it with a specific name. |
| `aws configure` | Interactively sets up credentials, region, and output format. |
| `nano ~/.aws/credentials` | Directly edits the file where AWS access keys are stored. |
| `aws ec2 describe-...` | Uses the CLI to retrieve specific details about your cloud infrastructure. |
