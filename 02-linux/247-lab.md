# Lab 247: Working with Commands (Tee, Sort, Cut, and Pipes)

## Objective
Master the use of advanced Linux CLI utilities to redirect output, sort data, and manipulate file content using pipes and delimiters.

## Key Concepts
* **Standard Output (stdout):** The default destination for command output (usually the screen).
* **Piping (|):** A method to take the output of one command and use it as the input for another.
* **Redirection:** Sending output to a file instead of the terminal.

## Task 2: Using the tee Command
The `tee` command is unique because it directs output to two places at once: the terminal screen and a file. It is named after the "T" shape in plumbing.

**Instructions:**
1. **Verify Location:** Ensure you are in the home directory:
   ```bash
   pwd
   ```
2. Execute the `tee` command to display the hostname and save it to `file1.txt`:
   ```bash
   hostname | tee file1.txt
   ```
3. Confirm the file creation:
   ```bash
   ls
   ```
## Task 3: Use the sort command and pipe operator
In this task, you use the `sort` command to reorder a list and the pipe operator to filter data.

**Instructions:**
1. Create a file named `test.csv`:
   ```bash
   cat > test.csv
   ```
    > **Technical Note:** Here, `cat` isn't showing a file; it's capturing your keystrokes (stdin) and the `>` operator is redirecting them into `test.csv.` This is a fast way to create small files without an editor.
2. Enter the following data (Press `CTRL+D` to save):
    ```plaintext
    Factory, 1, Paris
    Store, 2, Dubai
    Factory, 3, Brasilia
    Store, 4, Algiers
    Factory, 5, Tokyo
    ```
3. Sort the list alphabetically:
    ```bash
    sort test.csv
    ```
4. Search for the factory in Paris using a pipe:
    ```bash
    grep Paris test.csv
    ```
   > 💡**Pro-Tip**: The lab suggests using `find | grep Paris test.csv`, but find is designed to search for filenames, not text inside files. For professional efficiency, use `grep "pattern" filename` directly. It's faster and uses fewer system resources.

## Task 4: Use the cut command
The `cut` command extracts specific columns from each line based on a delimiter.
1. Create a file named `cities.csv` using the `cat >` method learned in Task 3.
2. Enter the following data (Press `CTRL+D` to save):
    ```plaintext
    Dallas, Texas
    Seattle, Washington
    Los Angeles, California
    Atlanta, Georgia
    New York, New York
    ```
3. Extract the first field (City name) using a delimiter:
    ```bash
    cut -d ',' -f 1 cities.csv
    ```

> **Command Explanation:**
> - `-d ','`: Specifies that the comma is the delimiter (separator). 
> - `-f 1`: Instructs the command to extract the first field only.


## Additional Challenge: The sed command
The `sed` command is used to replace text within a file without opening an editor manually.

**Instructions:**
1. Replace the first comma (`,`) with a period (`.`) in both files:
    ```bash
    sed 's/,/./' cities.csv
    sed 's/,/./' test.csv
    ```
> **Command Explanation:**
> - `s/old/new/`: This is the substitution syntax. It finds the first occurrence of the comma and swaps it for a period.
