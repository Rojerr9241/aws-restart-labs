# Lab 235: Working with Files and Backups ✅

## Objective
Learn how to create, document, and manage system backups in a Linux environment. This lab focuses on using the `tar` utility for archiving entire directory structures and using command redirection to create audit logs.

## Key Concepts
* **Archiving (`tar`):** The process of combining multiple files and directories into a single file (often called a "tarball").
* **Compression (`gz`):** Reducing the file size of an archive to save storage space and speed up transfers.
* **Piping (`|`):** Taking the output of one command and sending it as input to another command.
* **Redirection (`tee`):** A command that reads from standard input and writes to both standard output (terminal) and one or more files.


## Task 2: Creating a System Backup
Using the `tar` utility to capture the full state of the `CompanyA` directory.

**Command Breakdown:**
```bash
tar -cvpzf backup.CompanyA.tar.gz CompanyA
```

* `-c`: Create a new archive.
* `-v`: Verbose (lists files processed in the terminal).
* `-p`: Preserve permissions.
* `-z`: Compress the archive using `gzip`.
* `-f`: Specifies the filename of the archive.

>📝 **Technical Note:** Creating a compressed backup is a standard practice before performing major system changes or moving data between different hosts.

## Task 3: Logging the Backup (Auditing)
Documentation is vital for system administration. In this task, we create a log entry to track when the backup was created.

**Workflow:**

* Create a log file: `touch SharedFolders/backups.csv`
* Write the log entry using `tee`:
    ```bash
    echo "25 Aug 2021, 16:59, backup.CompanyA.tar.gz" | sudo tee SharedFolders/backups.csv
    ```

The `tee` command allows you to see the text in your terminal while simultaneously saving it to the CSV file.

## Task 4: Moving Backups to Infrequent Access (IA)
Organization of backups involves moving them to specific locations for long-term storage or team access.

**Commands:**

* Move: `mv ../backup.CompanyA.tar.gz IA/`
* Multi-Directory Verification: `ls . IA` 
    >*Note: This command lists the current directory (`.`) and target `IA` directory in one command*.


## 💡 Pro-Tips for File Operations

1. **Extracting Tarballs:** To restore or "unzip" the backup created in this lab, use the command `tar -xvpzf backup.CompanyA.tar.gz`. The `-x` flag stands for **eXtract**.
2. **Appending to Logs:** If you want to add a new entry to your `backups.csv` without overwriting the previous data, use the `tee -a` (append) flag.
3. **Naming Best Practices:** In production, it is highly recommended to include a date in the filename (e.g., `backup_2026_05_27.tar.gz`). This allows for easier version control and lifecycle management.
4. **Verification before Deletion:** Always use `tar -tf backup.tar.gz` to **list** the contents of an archive and verify its integrity before deleting the original source folders.

## Command Reference Summary

| Command | Action |
| :--- | :--- |
| `tar -cvpzf` | Creates a compressed archive (Archive + Compress). |
| `tar -xvpzf` | Extracts a compressed archive (Restore). |
| `echo "text" \| tee` | Displays output in terminal and writes to a file. |
| `tee -a` | Appends text to a file instead of overwriting it. |
| `mv [src] [dest]` | Moves a file or directory to a new location. |
| `ls -R` | Lists all files and subdirectories recursively. |
| `cat` | Displays the content of a file (e.g., the backup log). |
