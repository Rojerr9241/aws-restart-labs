# Lab 237: Linux File Permissions Management ✅

## Objective
Master the administration of file and directory security in a multi-user environment. This lab focuses on modifying ownership (users and groups) and managing access levels (Read, Write, Execute) using both symbolic and absolute methods.

## Key Concepts
* **Ownership (`chown`):** Defining which user and group "own" a specific resource.
* **Permissions (`chmod`):** Defining the actions (r, w, x) that the User, Group, and Others can perform.
* **Symbolic Mode:** Uses letters (`u, g, o`) and operators (`+, -, =`) to modify permissions.
* **Absolute (Numeric) Mode:** Uses a three-digit octal code (e.g., `755`) to set permissions exactly.
* **Recursive Flag (`-R`):** Applies changes to a folder and everything inside it.

## Task 3: Changing Permission Modes
Practicing the two ways to modify access rights.

### 1. Symbolic Mode
Used for targeted changes (adding or removing a specific right).
* **Command:** `sudo chmod g+w symbolic_mode_file`
* **Result:** Adds **Write** (`w`) permission to the **Group** (`g`) without affecting user or others.

### 2. Absolute (Numeric) Mode
Used for setting the complete permission set at once.
* **Command:** `sudo chmod 764 absolute_mode_file`
* **Breakdown (764):**
    - **7 (User):** Read(4) + Write(2) + Execute(1) = Full Control.
    - **6 (Group):** Read(4) + Write(2) = Read and Write.
    - **4 (Others):** Read(4) only.

## 💡 Pro-Tips for Permissions Management

1. **Numeric Cheat Sheet:** To calculate absolute mode, just add the values:
   - **4** = Read (r)
   - **2** = Write (w)
   - **1** = Execute (x)
   - *Example: Read (4) + Write (2) = **6**.*
2. **Directory Permissions vs. File Permissions:** - On a **file**, execute (`x`) allows you to run it as a program.
   - On a **directory**, execute (`x`) is required to enter (`cd`) the folder.
3. **The `chgrp` Command:** If you only need to change the group ownership without affecting the user owner, use `sudo chgrp [group_name] [resource]`.
4. **Security Best Practice:** Never use `chmod 777` in a production environment. It grants full control to everyone on the system, creating a significant security vulnerability. Always aim for the **Principle of Least Privilege**.

## Command Reference Summary

| Command | Action |
| :--- | :--- |
| `chown -R [u]:[g]` | Recursively changes both the owner and the group. |
| `chmod [mode]` | Changes file/directory access permissions. |
| `chmod g+w` | Symbolic mode: Adds write permission to the group. |
| `chmod 764` | Absolute mode: Sets rwx for user, rw for group, r for others. |
| `ls -laR` | Verifies permissions and ownership across the entire tree. |
| `vi` / `:wq` | Opens the text editor and saves/exits the file. |
