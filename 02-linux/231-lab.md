# Lab 231: Linux File Editing (Vim and Nano)

## Objective
Learn how to use the standard terminal-based text editors in Linux: **Vim** and **Nano**, focusing on file creation, modification, and saving procedures.

## Key Concepts
* **Services/Tools:** Linux CLI (Command Line Interface), Vim, Nano.
* **Difficulty:** Basic.
* **Vim Operation:** Switching between Normal Mode (commands) and Insert Mode (editing).

---

## Task 1: Running the Vim Tutorial (vimtutor)
The `vimtutor` is a built-in interactive lesson for learning the fundamentals of Vim.

**Instructions:**
1. **Start the tutorial:** Enter `vimtutor` in your terminal.
   *Note: If it's not installed, run `sudo yum install vim` first.*
2. **Follow Lessons:** Complete lessons 1 through 3 to practice cursor movement and basic editing.
3. **Exit the tutor:** Type `:q!` and press `Enter`.

---

## Task 2: Exercise - Editing a file in Vim
Vim is the standard editor for Linux administrators.

**Instructions:**
1. **Create a new file:** Run `vim helloworld`.
2. **Enter Insert Mode:** Press the `i` key and type the following text:
   > Hello World!
   > This is my first file in Linux and I am editing it in Vim!
3. **Save and Exit:** Press `ESC` to return to Normal Mode, then type `:wq` and press `Enter`.
4. **Modify the file:** Re-open it with `vim helloworld`, press the up arrow to recall the command if needed, and add:
   > I learned how to create a file, edit and save them too!
5. **Exit without saving:** Press `ESC`, type `:q!`, and press `Enter`.

---

## Task 3: Exercise - Editing a file in Nano
Nano is a more straightforward, modeless editor often used for quick changes.

**Instructions:**
1. **Create a new file:** Run `nano cloudworld`.
2. **Add Content:** Type the following (no special mode required):
   > We are using nano this time! We can simply start typing! No insert mode needed.
3. **Save Changes:** Press `CTRL + O` and then `Enter` to confirm the filename.
4. **Exit Nano:** Press `CTRL + X`.

---

## Additional Challenges & Useful Commands

| Command | Action (Vim) | Action (Nano) |
| :--- | :--- | :--- |
| **Delete full line** | `dd` | `CTRL + K` |
| **Undo last action** | `u` | `ALT + U` |
| **Save without quitting** | `:w` | `CTRL + O` |
| **Quit editor** | `:q` | `CTRL + X` |

> **Personal Note:** The main takeaway is the mode-based workflow of Vim compared to the "type-anywhere" workflow of Nano. Use Vim for efficiency and Nano for simplicity.
