# 172 - Challenge Lab: Deploying a Web Application on Amazon EC2

## Lab Overview
In this challenge, I designed and implemented a custom cloud infrastructure to host a web application. This involved configuring a virtual network from scratch, setting up security rules, and automating the web server installation using EC2 User Data.

---

## Task 1: Virtual Private Cloud (VPC) Infrastructure
Before launching the instance, I established the networking foundation to ensure internet reachability.

1.  **VPC Creation:** Created a new VPC named `Lab-VPC` with a CIDR block of `10.0.0.0/16`.
2.  **Subnet Configuration:** Created `Lab-Subnet` within the VPC using `10.0.1.0/24`.
3.  **Internet Gateway (IGW):**
    * Created `Lab-IGW`.
    * Attached the IGW to the `Lab-VPC` to enable communication between the VPC and the internet.
4.  **Route Table (RT):**
    * Configured `Lab-RT` and added a route: `0.0.0.0/0` -> `Lab-IGW`.
    * Associated the route table with `Lab-Subnet` to make it a **Public Subnet**.

---

## Task 2: Security Group Configuration
To protect the instance while allowing necessary web traffic, I configured a stateful firewall.

* **Security Group Name:** `Lab-SG`.
* **Inbound Rules:**
    * **SSH (Port 22):** Allowed from `0.0.0.0/0` (for EC2 Instance Connect).
    * **HTTP (Port 80):** Allowed from `0.0.0.0/0` to serve the web page.
    * **HTTPS (Port 443):** Allowed from `0.0.0.0/0` for secure traffic.

---

## Task 3: Launching the EC2 Web Server
I provisioned the compute resource using automation to ensure the software stack was ready upon boot.

1.  **Instance Details:**
    * **Name:** `Lab-WebServer`.
    * **AMI:** Amazon Linux 2023.
    * **Instance Type:** `t3.micro`.
2.  **Network Settings:** Selected `Lab-VPC`, `Lab-Subnet`, and enabled **Auto-assign Public IP**.
3.  **User Data (Automation Script):**
    I used the following script to install the Apache web server and set folder permissions automatically:
    ```bash
    #!/bin/bash
    yum update -y
    yum install httpd -y
    systemctl start httpd
    systemctl enable httpd
    chmod 777 /var/www/html
    ```
