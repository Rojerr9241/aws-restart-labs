# Lab 269: Insert, Update, and Delete Data in a Database

## Objective
Master the core Data Manipulation Language (DML) operations in a MySQL environment. This lab focuses on manually adding records, performing bulk updates and deletions, and using SQL scripts to import large datasets into a relational database.

## Key Concepts
* **SQL (Structured Query Language):** The standard language for interacting with relational database management systems.
* **DML (Data Manipulation Language):** SQL statements used to manage data within tables (INSERT, UPDATE, DELETE).
* **Foreign Key Checks:** A safety mechanism in databases to maintain referential integrity between tables.
* **SQL Script Import:** The process of executing a file containing multiple SQL commands to quickly populate or restore a database.

## 💡 Pro-Tips for Database Administration

1. **The Dangerous Delete:** In a production environment, always run a `SELECT` statement with your `WHERE` clause **before** running a `DELETE` or `UPDATE`. This allows you to verify exactly which rows will be affected before committing to a change.
2. **Redirection Operator (`<`):** Using the `<` symbol in the Linux terminal is the most efficient way to "pipe" a SQL script into the database engine. This is the standard method for restoring backups or migrating data.
3. **Foreign Key Awareness:** Disabling `FOREIGN_KEY_CHECKS` is a powerful tool for cleaning or restructuring data, but it should be used with extreme caution. Always remember to re-enable it (set to `1`) to maintain the integrity of your relational model.
4. **Case Sensitivity:** While SQL keywords (like `SELECT` or `FROM`) are case-insensitive, table names and data values within single quotes (like `'Ireland'`) are often case-sensitive depending on the database configuration.
5. **No Undo:** Unlike a text editor, standard SQL commands like `DELETE` and `UPDATE` in this lab environment do not have an "undo" button. Always double-check your syntax before pressing Enter.

## SQL Command Reference Summary

| Command | Action |
| :--- | :--- |
| `SHOW DATABASES;` | Lists all logical databases available on the server. |
| `USE world;` | Selects the "world" database for subsequent queries. |
| `SELECT * FROM [table]` | Retrieves all columns and all rows from a specified table. |
| `INSERT INTO [table] VALUES (...)` | Adds a new record to the table (values must match schema order). |
| `UPDATE [table] SET [col] = [val]` | Modifies existing data within a table. |
| `DELETE FROM [table]` | Removes data from a table (removes all rows if no `WHERE` is used). |
| `SET FOREIGN_KEY_CHECKS = 0;` | Disables safety constraints to allow deletion of related data. |
| `QUIT;` | Exits the MySQL interactive shell. |
