# Lab 270: Selecting Data from a Database

## Objective
Master the use of the `SELECT` statement and common database operators to query a relational database. This lab focuses on data retrieval, filtering results based on specific conditions, ordering data for better readability, and using aggregation functions like `COUNT()`.

## Key Concepts
* **SELECT Statement:** The primary SQL command used to retrieve data from one or more tables.
* **Filtering (`WHERE`):** A clause used to extract only those records that fulfill a specified condition.
* **Ordering (`ORDER BY`):** A clause used to sort the result-set in ascending (`ASC`) or descending (`DESC`) order.
* **Aggregation (`COUNT`):** A function that returns the number of rows that matches a specified criterion.
* **Aliasing (`AS`):** Used to give a table, or a column in a table, a temporary name to make results more user-friendly.

### 💡 Challenge: Answering Business Questions
Question: Which country in "Southern Europe" has a population over 50,000,000?

**The Solution:**
```SQL
SELECT Name, Capital, Region, Population 
FROM world.country 
WHERE Population > 50000000 AND Region = "Southern Europe";
```

## 💡 Pro-Tips for Data Selection

1. **Efficiency with SELECT:** Avoid using `SELECT *` in production applications. Instead, specify only the exact columns you need. This reduces memory usage and improves query performance.
2. **Strict Clause Order:** SQL requires clauses to follow a specific sequence. If you put `ORDER BY` before `WHERE`, the query will fail. The standard flow is:
   1. `SELECT` (What)
   2. `FROM` (Where from)
   3. `WHERE` (Conditions)
   4. `ORDER BY` (Sorting)
3. **The Power of DESC:** Use `DESC` to quickly identify outliers or "Top" lists, such as the most populated countries or the highest-grossing products.
4. **Quotes Best Practice:** Use **Single Quotes** (`' '`) for text values (e.g., `'Southern Europe'`) and **Double Quotes** (`" "`) for column aliases that contain spaces (e.g., `"Surface Area"`).
5. **Counting Nulls:** Remember that `COUNT(*)` counts every row including those with empty data, while `COUNT(ColumnName)` only counts rows where that specific column has a value.


## SQL Operator Reference Summary

| Operator / Clause | Purpose |
| :--- | :--- |
| `SELECT` | Specifies which columns to retrieve from the database. |
| `AS` | Creates a temporary alias for a column (e.g., for cleaner reports). |
| `COUNT()` | Aggregates data to show the total number of records. |
| `WHERE` | Filters the result-set based on specific criteria. |
| `ORDER BY` | Sorts the records (Ascending by default). |
| `DESC` | Reverses the sort order to Descending. |
| `AND` | Logical operator used to combine multiple filters in a `WHERE` clause. |
| `>, <, =` | Comparison operators used to evaluate numerical or text data. |
