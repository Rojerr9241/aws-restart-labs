## Objective
Harness the power of built-in SQL functions to summarize, manipulate, and clean data. This lab covers aggregate functions for numerical analysis and string functions for text processing, as well as the use of `DISTINCT` to handle duplicate records.

## Key Concepts
* **Aggregate Functions:** Functions that perform a calculation on a set of values and return a single value (`SUM`, `AVG`, `MIN`, `MAX`, `COUNT`).
* **String Manipulation:** Functions used to edit or split text data (e.g., `SUBSTRING_INDEX`).
* **Data Cleaning:** Using `TRIM` to remove unwanted spaces and `LENGTH` to measure data size.
* **De-duplication:** Using `DISTINCT` to ensure the results only show unique values.

## Task 2: Advanced Data Manipulation
1. Numerical Aggregation
We summarized the global population statistics using multiple functions in a single query:
```SQL
SELECT sum(Population), avg(Population), max(Population), min(Population), count(Population) 
FROM world.country;
```
* SUM: Total global population.
* AVG: Mean population per country.
* MAX/MIN: Outliers (largest and smallest countries).

2. String Splitting with `SUBSTRING_INDEX`
We used this function to extract parts of a string based on a delimiter (like a space or a slash):
```SQL
-- Extracts the first word of the Region (e.g., "North" from "North America")
SELECT Region, substring_index(Region, " ", 1) FROM world.country;
```

3. Cleaning and Filtering by Length
Combining `TRIM()` and `LENGTH()` allows for precise filtering of text data:
```SQL
-- Finds unique regions with short names (less than 10 characters)
SELECT DISTINCT(Region) 
FROM world.country 
WHERE LENGTH(TRIM(Region)) < 10;
```
* TRIM: Removes accidental spaces at the beginning or end.
* DISTINCT: Prevents "Europe" from appearing multiple times in the list.

### 💡 Challenge: Splitting Delimited Strings
Question: Split "Micronesia/Caribbean" into two separate columns.

**The Solution:**

```SQL
SELECT Name, 
       substring_index(Region, "/", 1) AS "Region Name 1",
       substring_index(Region, "/", -1) AS "Region Name 2" 
FROM world.country 
WHERE Region = "Micronesia/Caribbean";
```
Note: Using `-1` in `substring_index` counts from the right, effectively grabbing the last part of the string.

## 💡 Pro-Tips for Using Functions

1. **Functions in the WHERE Clause:** You can use functions to filter data based on its "shape." For example, `WHERE LENGTH(Name) > 15` finds countries with long names, while `WHERE YEAR(IndepYear) > 1990` filters by date.
2. **DISTINCT vs. GROUP BY:** Use `DISTINCT` when you simply want to remove duplicate rows from your view. Use `GROUP BY` when you want to remove duplicates AND perform math (like total population per region).
3. **The Importance of TRIM:** Data imported from external sources often contains "hidden" spaces (e.g., `"Europe "`). Always use `TRIM()` when comparing lengths or performing exact matches to ensure your queries don't miss records due to formatting errors.
4. **Mastering Negative Indexes:** In `SUBSTRING_INDEX(string, delimiter, count)`, using a negative count (like `-1`) returns everything to the **right** of the delimiter. This is a pro move for extracting the last part of a string, like a last name or a file extension.
5. **Function Nesting:** You can nest functions like layers: `SELECT UPPER(TRIM(Name))`. SQL processes the innermost function first (`TRIM`) and then applies the outer one (`UPPER`) to the result.
