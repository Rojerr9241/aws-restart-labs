## 💡 Expert Pro-Tips
* **Security Group Logic:** RDS is in a private subnet. The only way to access it is through the LinuxServer. Your Security Group must allow Inbound TCP 3306 where the source is the Security Group ID of the LinuxServer.

* **Endpoint vs. Hostname:** In your connection command, never use the IP address of the RDS. Always use the Endpoint DNS. If AWS performs maintenance or a failover, the IP might change, but the DNS will automatically point to the new IP.

* **ACID Compliance:** By using MySQL on RDS, you are ensuring ACID (Atomicity, Consistency, Isolation, Durability) properties, which are critical for relational data integrity.

* **GP2 vs GP3:** The lab requires GP2. In a real-world scenario, GP3 is usually preferred as it provides baseline performance (3,000 IOPS) regardless of storage size, often at a lower cost.
